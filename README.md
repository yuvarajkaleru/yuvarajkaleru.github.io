# Kaleru Yuvaraj — Portfolio

Personal portfolio site. Plain HTML, CSS and JavaScript — no build step.

## Files
- `index.html` — page content
- `styles.css` — styles
- `main.js` — API console, mobile menu, certificate viewer, copy-email
- `assets/` — photo, resume PDF, certificate images

## Publish on GitHub Pages
1. Create a new public repo named exactly **`yuvarajkaleru.github.io`**.
2. Upload all files in this folder (keep the `assets` folder structure) to the repo root and commit.
3. Open **Settings → Pages**, set Source to **Deploy from a branch**, branch **main**, folder **/ (root)**, and save.
4. After a minute the site is live at **https://yuvarajkaleru.github.io**.

## Updating
- Replace `assets/Kaleru_Yuvaraj_Resume.pdf` to update the resume (keep the same file name).
- Projects, skills and certificates are plain HTML sections in `index.html`.
- The hero console text lives in the `responses` object at the top of `main.js`.
